# Contributing

Thank you for improving Weather Info Display.

1. Fork the repository and create a focused branch.
2. Install Node.js 24 or newer and run `npm ci`.
3. Make the change without adding API keys or personal location data as defaults.
4. Run `npm test`, `npm run lint`, and `npm run format:check`.
5. If weather fields changed, also run `npm run smoke`.
6. Open a pull request describing the user-visible effect and kiosk/browser testing performed.

Keep source code and documentation in English. Preserve Berlin-Adlershof as the default example unless the project scope changes.

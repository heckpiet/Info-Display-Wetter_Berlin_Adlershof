# Provider proxy

This directory contains the optional Cloudflare Worker introduced in v3.0.0. It is not required for the default Open-Meteo DWD ICON configuration.

Read the complete [prerequisites, provider requirements, secure deployment procedure, go-live checklist, and production limitations](../docs/WEATHER_PROVIDERS.md#prerequisites) before deploying it.

Never commit API keys, Cloudflare tokens, internal ingestion URLs, or personal contact details intended to remain private.

# Security policy

## Supported version

Only the latest version on `main` receives security updates.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, private deployment URLs, or credentials.

This project does not require secrets. Never add API keys to `config.js`, URLs, source code, workflow files, or browser storage. If a future provider requires a secret, use a server-side proxy rather than exposing it in this static application.
